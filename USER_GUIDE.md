# RTT Ranging Tool User Guide

## 1. Introduction and Overview

The **RTT Ranging Tool** (`rttrange`) is an interactive, browser-based
scientific visualization, statistical analysis, and parameter optimization
platform designed for Wi-Fi Round-Trip Time (RTT / Wi-Fi FTM — IEEE 802.11mc
and IEEE 802.11az) ranging, distance estimation, and indoor Access Point (AP)
localization.

The tool operates entirely client-side using standard web technologies (HTML5,
CSS3, Canvas, and vanilla JavaScript). No server-side components, backend
databases, or cloud network calls are required; all log parsing, numerical
optimization, statistical charting, and spatial geometry algorithms execute
locally in your browser, guaranteeing complete data privacy and responsiveness.

### Core Capabilities

The platform is structured into two dedicated operating modes accessible via the
top navigation tabs:

1.  **Range Analysis Tab (Default)**: In-depth statistical analysis of Wi-Fi RTT
    distance measurements recorded by **WiFiRttScan** (an Android application
    developed by Google and freely available on Google Play). It generates eight
    configurable analytical charts including error Cumulative Distribution
    Functions (CDFs), measurement spread distributions, linear fit trendlines,
    RSSI correlations, sampling interval metrics, and theoretical Cramer-Rao
    Lower Bound (CRLB) models across 2.4 GHz, 5 GHz, and 6 GHz (Wi-Fi 6E/7)
    frequency bands.
2.  **AP Location Tab**: Trajectory reconstruction and indoor localization using
    Pedestrian Dead Reckoning (PDR) step logs and RTT ranging circles. It solves
    for AP coordinates $(x, y)$ and hardware ranging bias ($T_b$) using
    non-linear Gauss-Newton least-squares optimization, filters multipath
    outliers with spatial RANSAC, calibrates step length via gradient descent,
    and quantifies accuracy against interpolated ground truth survey routes.

### Supported Data Formats

The tool natively parses CSV log files generated by the **WiFiRttScan** app:

-   **RANGE Logs** (`Range Log CSV`): Multi-point distance calibration logs
    containing timestamped Wi-Fi RTT ranging events, actual distances, estimated
    distances, standard deviations, RSSI signal levels, BSSIDs, frequencies, and
    negotiated channel bandwidths.
-   **FIND Logs** (`FIND Log CSV`): Continuous walking logs recorded during
    pedestrian movement, containing PDR step increments, orientation headings,
    RTT range estimates to candidate APs, measurement success counts, and
    optional ground truth surveyor markers.
-   **Ground Truth Files** (`gt_coords.csv`): Surveyor ground truth coordinates
    specifying known benchmark positions `(x, y)` at discrete timestamps or step
    indices.

## 2. User Interface Overview

The interface consists of three primary regions:

```text
+-----------------------------------------------------------------------------+
| RTT Ranging Tool               [ Range Analysis ] [ AP Location ]           |
+--------------------------+--------------------------------------------------+
| LEFT PANEL (Controls)    | RIGHT PANEL (Visualization Workspace)            |
| - Subpanels (Collapsible)|                                                  |
| - Parameter Inputs       | - Multi-Chart Grid (Range Analysis Mode)         |
| - Reset & Default Buttons|   OR                                             |
|                          | - Interactive Canvas Map (AP Location Mode)      |
|                          |   with Zoom, Pan, Legend, & AP Direction Panel   |
+--------------------------+--------------------------------------------------+
```

1.  **Navigation Header**: Displays the application branding and mode switch
    buttons (`Range Analysis` and `AP Location`).
2.  **Left Sidebar (Controls)**: A vertical panel with an adjustable width
    (default 420 px) containing grouped, color-coded subpanels. Each subpanel
    can be collapsed or expanded via its header checkbox, or reset to the
    start-up defaults via its individual `defaults` button. A purple `reset`
    button at the top clears all loaded datasets, and an `All defaults` button
    restores all parameters simultaneously.
3.  **Draggable Divider**: A 5 px divider between the left and right panels.
    Drag horizontally to resize the panels, or click the collapse button
    (`«` / `»`) to instantly hide or reveal the sidebar.
4.  **Right Panel (Workspace)**: Displays responsive analytical charts when
    operating in the Range Analysis tab, or an interactive, hardware-accelerated
    HTML5 Canvas map with pan and zoom capabilities when operating in the AP
    Location tab.

## 3. Tab 1: Range Analysis (Detailed Reference)

The **Range Analysis** tab is the default landing mode. It provides deep
statistical characterization of static or stepped ranging measurements to
evaluate radio performance, antenna calibration, channel bandwidth impact, and
multipath effects.

### 3.1 File Subpanel

-   **`drag` Checkbox**: When checked, replaces the file picker button and text
    box with a large drag-and-drop target area. Default: `false`.
-   **`reset` Button (Purple)**: Clears all loaded datasets from memory, clears
    the browser's local IndexedDB cache, re-establishes the default file prompt
    (`Range Log CSV`), and clears the right panel to a solid white canvas.
-   **`All defaults` Button**: Resets all parameters across all subpanels on the
    Range Analysis tab back to their factory defaults.
-   **`Range Log CSV`**: File input or drag target for loading WifiRttScan RANGE
    CSV logs.
-   **`Reload Previous Files` Button**: Restores the previously loaded dataset
    and parameters cached in local browser IndexedDB storage without needing to
    reselect the file from disk.
-   **`Toggle Show[]` Button (Blue)**: Inverts the expanded/collapsed state of
    all subpanels (Data, Parameters & Filters, and Charts) and their child
    parameter sections simultaneously.

### 3.2 Data Subpanel

-   **`defaults` Button**: Resets data textboxes.
-   **`show` Checkbox**: Expands or collapses the yellow Data subpanel (default:
    collapsed).
-   **`Raw Data`**: Read-only monospace preview of the raw CSV records.
-   **`Parsed Data`**: Monospace preview of parsed data including detected
    device, bandwidth, channel, frequency, and sample statistics.

### 3.3 Parameters & Filters Subpanel

The green **Parameters & Filters** subpanel configures data filtering, bias
compensation, time bounds, and theoretical models for all range charts.

-   **`defaults` Button**: Resets all parameters across all sections in this
    subpanel back to their factory defaults.
-   **`show` Checkbox**: Expands or collapses the entire subpanel.

#### Section 1: Estimated vs Actual Distance

-   **`show` Checkbox**: Expands or collapses this section.
-   **`Device/OS`**: Text input specifying the testing device and operating
    system (default: `Pixel/OS`). Displayed in chart titles.
-   **`Bandwidth`**: Wi-Fi channel bandwidth (default: `80MHz`).
-   **`auto` Checkbox**: When checked (default: `true`), automatically infers
    the channel bandwidth (20, 40, 80, 160, or 320 MHz) from the channel or
    frequency detected in the loaded log.
-   **`Remove Bias` Checkbox**: When checked (default: `true`), subtracts the
    linear regression intercept ($d_{\text{unbiased}} = d_{\text{est}} - c$)
    so that the regression fit passes through the origin.
-   **`Filter Data` Checkbox**: When checked (default: `true`), filters out data
    points falling outside the minimum and maximum distance bounds.
-   **`Trendline` Checkbox**: When checked (default: `true`), renders the linear
    regression fit ($y = mx + c$) on the scatter plot.
-   **`Perfect Distance` Checkbox**: When checked (default: `false`), renders a
    dashed green 1:1 reference line representing ideal zero-error ranging.
-   **`Filter Dist Min (m)` & `Filter Dist Max (m)`**: Numeric inputs and dual
    slider (-5 m to 100 m, default: `-1` m to `11` m) setting the active
    distance filtering bounds.

#### Section 2: Distribution of Range Error

-   **`show` Checkbox**: Expands or collapses this section.
-   **`Signed Distribution Error` Checkbox**: When checked (default: `true`),
    evaluates signed residuals ($d_{\text{est}} - d_{\text{act}}$) to reveal
    directional over- or under-ranging. When unchecked, evaluates absolute
    unsigned errors ($|d_{\text{est}} - d_{\text{act}}|$).

#### Section 3: Time Window for all Charts

-   **`show` Checkbox**: Expands or collapses this section.
-   **`Min (s)` & `Max (s)`**: Numeric inputs and dual slider (default: `0` s to
    `100` s) to restrict analysis across all charts to a specific time interval.

#### Section 4: Cramer Rao Lower Bound (CRLB)

Calculates the theoretical range error standard deviation bound:
$$\sigma_{\text{LB}} = \frac{c}{2\sqrt{2}\pi \cdot B \cdot \sqrt{\text{SNR}}}$$
where $c$ is the speed of light, $B$ is channel bandwidth in Hz, and
$\text{SNR}$ is the dimensionless linear power ratio. Input values (SNR in dB
or RSSI in dBm) are converted to a linear power ratio ($10^{\text{SNR}/10}$ or
$10^{(\text{RSSI} - P_{\text{noise}})/10}$) prior to computing the bound.

-   **`show` Checkbox**: Expands or collapses this section (default: collapsed).
-   **`Noise Floor`**: Slider configuring receiver noise floor from -110 dBm to
    -60 dBm (default: `-90 dBm`).
-   **`RSSI Range`**: Dual slider setting minimum and maximum RSSI evaluation
    bounds from -110 dBm to -10 dBm (default: `-90 to -30 dBm`).
-   **`Bandwidth Range`**: Dual slider selecting the active range of bandwidths
    evaluated on the CRLB chart (20 MHz to 320 MHz).
-   **`Use SNR` Checkbox**: When checked (default: `true`), plots CRLB variance
    against SNR (dB); when unchecked, plots against RSSI (dBm).

### 3.4 Chart Subpanel

-   **`defaults` Button**: Resets chart layout options (`Nx2`, `4x3`, `25%`,
    unchecks `(include filename)`) and checks all 8 chart checkboxes.
-   **`show` Checkbox**: Expands or collapses the Chart subpanel.
-   **`Format` Radio**: Grid layout formatting chart cards into `Nx1`, `Nx2`,
    or `Nx3` columns. Default: `Nx2`.
-   **`Aspect Ratio` Radio**: Canvas container aspect ratio: `4x3`, `16x9`, or
    `Best Fit`. Default: `4x3`.
-   **`Minor grids` Radio**: Grid division density: `None`, `50%`, `25%`, or
    `10%`. Default: `25%`.
-   **`(include filename)` Checkbox**: Displays the filename loaded for analysis
    in a small black font at the bottom left of each rendered chart box.
    Default: `false`.
-   **`Select All` / `Unselect All`**: Convenience buttons above the chart list
    to check or uncheck all 8 analytical charts at once.
-   **Individual Chart Checkboxes**:
    1.  *Estimated vs. Actual Distance*: Scatter plot comparing RTT-estimated
        distance against surveyor ground truth distance. Includes an ideal 1:1
        reference line and a linear regression fit ($y = mx + c$). Clicking
        any data point opens the detailed Distribution Spread modal.
    2.  *CDF of Range Errors*: Cumulative distribution function of unsigned
        range errors $|d_{\text{est}} - d_{\text{act}}|$, displaying key
        percentiles (50th / median, 68th / $1\sigma$, 90th, 95th, 99th, and
        maximum error).
    3.  *Spread vs. Actual Distance*: Plots the spread (max minus min range
        estimate) and the reported standard deviation at each discrete actual
        distance.
    4.  *Distribution of Range Error*: Histogram binning of range errors,
        configurable as signed ($d_{\text{est}} - d_{\text{act}}$) or unsigned,
        with summary statistics including cdf99 and max error.
    5.  *Distance vs. Std.Dev & RSSI*: Dual-axis chart correlating actual
        distance against measurement standard deviation (left Y-axis) and
        received signal strength (RSSI, right Y-axis).
    6.  *Std.Dev vs. RSSI*: Scatter plot analyzing measurement noise and jitter
        as a function of received signal power.
    7.  *Estimated Distance vs. Time*: Time-series showing range estimates over
        the duration of the test, displaying sampling interval statistics
        (sample count, mean interval, mean frequency in Hz, min, and max).
    8.  *Cramer-Rao Lower Bound (CRLB)*: Theoretical lower variance bound of RTT
        time-of-arrival estimation plotted against SNR or RSSI across multiple
        bandwidths.

### 3.5 Interactive Distribution Spread Modal

Clicking any data point on the *Estimated vs. Actual Distance* chart opens a
modal dialog titled **"Estimated Range Distribution Spread at Specific Actual
Distance"**. This dialog renders a high-resolution histogram and kernel spread
of all measurements recorded at that exact distance benchmark.

-   **`Save PNG` Button**: Exports the distribution diagram as a PNG graphic.
-   **`Close` Button / `×`**: Dismisses the modal.

## 4. Tab 2: AP Location (Detailed Reference)

The **AP Location** tab reconstructs pedestrian paths and estimates the physical
indoor coordinates $(x, y)$ of the target Access Point using multilateration
and non-linear least-squares optimization.

### 4.1 File Subpanel

-   **`drag` Checkbox**: Replaces file inputs with drag-and-drop dropzones.
-   **`reset` Button (Purple)**: Clears all loaded PDR logs, targets, and ground
    truth points from the workspace.
-   **`All defaults` Button**: Resets all algorithm, solver, filter, and
    playback parameters across the AP Location subpanels.
-   **`Log CSV`**: File input for the continuous walking CSV log (hint: `"FIND
    Log CSV"`).
-   **`Ground Truth CSV`**: Optional surveyor coordinate benchmark file
    (`gt_coords.csv`).
-   **`Toggle all show[]` Button (Blue)**: Inverts the expanded/collapsed state
    of all subpanels on the AP Location tab simultaneously.

### 4.2 Data Subpanel

-   **`show` Checkbox**: Expands the subpanel to view a scrollable, read-only
    monospace preview of the raw loaded CSV records.

### 4.3 Playback Subpanel

Controls step-by-step replay and animation of the walking trajectory:

-   **`Screenshot` Button**: Captures a high-resolution PNG snapshot of the
    current canvas view.
-   **`Record` Checkbox**: When checked, automatically captures and downloads a
    PNG image for every step advanced during an animation sequence.
-   **`defaults` Button**: Resets playback range and speed to defaults.
-   **Dual Slider (`slider-min` & `slider-max`)**: Sets the active step window
    $[S_{\text{min}}, S_{\text{max}}]$ for filtering measurements.
-   **`Animate` Button**: Plays through the trajectory step-by-step.
-   **`Reset` Button**: Restores the playback window to step 0 through the end
    of the log.
-   **`Delay (ms)`**: Frame delay between animation steps (default: `250` ms).
-   **`Decrement` / `Increment`**: Advances or steps backward by one step.
-   **`Cancel`**: Halts an active animation.

### 4.4 Enhanced Input Subpanel

Fine-tunes Pedestrian Dead Reckoning (PDR) path reconstruction and ranging
inputs:

-   **`Initial Step Length (m)`**: Starting estimate of distance traversed
    per pedestrian footstep. The gradient descent algorithm will update this
    value during spatial optimization to provide a best fit for the range
    data. Default: `0.67` meters.
-   **`Diversity (m)`**: Minimum distance threshold between successive ranging
    measurements required before computing a new multilateration position.
    Default: `0.8` meters.

#### 4.4.1 Filter Inputs

Excludes unreliable or multipath-degraded ranging measurements:

-   **`RSSI filter (dBm)`**: Discards measurements weaker than this signal
    threshold. Default: `-95` dBm.
-   **`Successes in Burst`**: Minimum number of successful RTT frames
    required per burst (1 to 8). Default: `5`.
-   **`Std. Dev. (m)`**: Discards measurements with standard deviation
    greater than this threshold. Default: `2.0` meters.
-   **`Limit steps to GT-1`**: When checked (default: `true`), restricts
    processing to steps up to one step before the ground truth endpoint.
-   **`Only use max Last N Steps`**: Slider (1 to 100, default: `100` / `All`)
    restricting the multilateration window to only the most recent $N$ steps.

#### 4.4.2 Range Bias Removal

Configures hardware time-of-arrival delay and scaling compensation:

-   **Mode Radios (`None`, `Auto`, `Manual`)**: Selects the bias removal mode:
    -   *None*: Uses uncorrected raw ranging measurements (default).
    -   *Auto*: Uses the range bias parameter ($T_b$) estimated directly by the
        Gauss-Newton solver.
    -   *Manual*: Applies a fixed user-defined offset in meters.
-   **`Manual Bias (m)`**: User-specified offset subtracted from range estimates
    when in manual mode. Default: `0.5` m.
-   **`Scale Range`**: Multiplicative scale factor applied to range estimates.
    Default: `0.93`.
-   **`Bias (m)`**: Read-only display of the active range bias value.

### 4.5 Gauss-Newton Optimization Subpanel (NG Solver)

Non-linear least-squares solver estimating the indoor AP coordinate $(x, y)$:

-   **`defaults` Button**: Resets all solver settings to default values.
-   **`show` Checkbox**: Expands or collapses the subpanel.
-   **`Initialization` Radios**: Selects the starting coordinate $(x_0, y_0)$:
    -   *First PDR Position* (default): Starts at the initial step position.
    -   *Centroid of Steps*: Starts at geometric average $(\bar{x}, \bar{y})$.
    -   *Linear Least Squares*: Computes an algebraic initial estimate via LLS.
    -   *Last PDR Position*: Starts at the prior recorded step position.
-   **`Weight by RSSI` Radios**:
    -   *None* (default): Equal weighting across signal strengths.
    -   *1 / abs(RSSI)*: Weights inversely proportional to signal attenuation.
    -   *Linearized RSSI*: Weights using linear power converted from dBm.
-   **`Weight by Range` Radios**:
    -   *None* (default): Equal weighting across distance estimates.
    -   *1 / r*: Weights inversely proportional to distance.
    -   *1 / r²*: Weights inversely proportional to squared distance.
-   **`Additional Weights` Checkboxes**:
    -   *Weight by Successes* (default: `false`): Weights steps proportionally
        to the number of successful RTT frames in the measurement burst.
    -   *Weight by 1 / sd²* (default: `false`): Weights steps inversely
        proportional to measurement variance.
-   **`Enhanced NG Position RMS Error (m)`**: Read-only display of the
    root-mean-square residual error of the solved AP position.

*Internal Operation*: The solver minimizes the residual error function
$r_i(x, y, T_b) = \sqrt{(x - x_i)^2 + (y - y_i)^2} + T_b - d_i$ across all
valid ranging steps. The algorithm runs internally with a fixed limit of $50$
maximum iterations and a convergence threshold criterion of
$\|\Delta \theta\| < 0.001$ meters.

### 4.6 Spatial Optimization Subpanel

Filters multipath reflections and refines step length calibration:

-   **`defaults` Button**: Resets spatial optimization mode to `None`.
-   **`show` Checkbox**: Expands or collapses the subpanel.
-   **`Spatial Optimization Mode` Radios**:
    -   *None* (default): Standard solver without outlier filtering.
    -   *Auto step length by Gradient Descent (GD) ONLY*: Iteratively tunes
        pedestrian step length to minimize residual errors.
    -   *Bucket Consensus (BC) RANSAC ONLY*: Filters multipath outlier
        circles using spatial bucket consensus.
    -   *BC RANSAC with auto step length GD*: Combines BC RANSAC outlier
        filtering with gradient descent step length calibration.
-   **`Estimated Step Length (m)`**: Read-only display of the automatically
    calibrated step length produced by gradient descent.

*Internal Operation*: Bucket Consensus (BC) RANSAC groups ranging circles into
angular and distance buckets, identifying spatial consensus subsets to discard
non-line-of-sight (NLOS) reflections. Gradient Descent (GD) optimizes step
length dynamically to minimize global trajectory closure error.

### 4.7 Parameter Optimization Subpanel

Automates parameter tuning across the multidimensional parameter space:

-   **`defaults` Button**: Resets optimization goals and progress counter.
-   **`show` Checkbox**: Expands or collapses the subpanel.
-   **Optimization Goal Checkboxes**:
    -   `Minimise Mean Enhanced Angle Error`: Tunes for bearing accuracy.
    -   `Minimise Mean Enhanced Distance Error`: Tunes for position accuracy.
    -   `Minimise Enhanced NG Position RMS Error`: Tunes for residual fit.
-   **`Progress`**: Read-only text box reporting completed iterations out of
    the total candidate pool (e.g., `0 / 1728`).
-   **`Start` Button**: Executes the parameter sweep and applies the winning
    parameter set to the workspace.

*Internal Operation*: A grid search evaluates 1,728 parameter combinations
across step lengths, diversity thresholds, RSSI cutoffs, burst success counts,
and weighting models, scoring each configuration against the selected goals.

### 4.8 Metrics Subpanel

Evaluates localization and tracking accuracy against ground truth:

-   **`defaults` Button**: Resets metrics modal options.
-   **`show` Checkbox**: Expands or collapses the subpanel.
-   **`Generate CDFs` Button**: Opens a modal displaying Cumulative Distribution
    Function curves for distance error (m) and bearing error (degrees), with
    `Save CSV` and `Save PNG` export buttons.
-   **`Step Charts` Button**: Opens a modal displaying step-by-step distance and
    bearing error series across the duration of the walk.

*Internal Operation*: Statistical metrics are calculated by interpolating the
pedestrian position against surveyor ground truth benchmarks (`gt_coords.csv`)
at matching timestamps or step indices.

### 4.9 Interactive Canvas Map, Legend, & AP Direction Panel

The right-side canvas renders the walking trajectory and AP estimates with
hardware-accelerated 2D graphics:

#### Canvas Controls & Interaction

-   **Pan**: Drag any empty canvas area to move the map.
-   **Zoom In (`+`) / Zoom Out (`-`)**: Scales the view relative to the center.
-   **Zoom Reset (`Reset`)**: Re-centers and fits the entire trajectory.

#### Visual Elements

-   **Red Solid Line**: Phone PDR trajectory path.
-   **Red Arrows**: Footstep heading vectors.
-   **Green Diamond**: Found step marker (where RTT target criteria were met).
-   **Grey Circles**: RTT ranging distance circles centered on the phone
    position at each step.
-   **Blue Dot**: Estimated AP position computed from Phone PDR.
-   **Green Line & Points**: Interpolated surveyor Ground Truth path.
-   **Neon Green Dot**: True AP coordinate specified in Ground Truth.
-   **Orange Line**: Enhanced PDR trajectory (with calibrated step length and
    filtering).
-   **Purple Dashed Circles**: Enhanced ranging circles.
-   **Purple Dot**: Enhanced estimated AP position.

#### Dynamic Legend Box (Top Right)

A grey-background control box positioned in the upper right of the canvas:

-   **Header**: Features a **`[x] show`** checkbox. When unchecked, collapses
    the legend and hides the attached AP Direction panel.
-   **Layer Toggles**: Checkboxes toggling visibility for each individual
    visual element (`PDR Path`, `PDR Arrows`, `Found Step`, `Range Circles`,
    `AP Target`, `Ground Truth`, `True Target`, `Enhanced Path`,
    `Enhanced Range`, `Enhanced Target`, `Enhanced Found Step`,
    `Enhanced Found Pos`, `Enhanced Arrows`).
-   **`include filenames`**: Checkbox (default unchecked) that renders the
    loaded FIND log and ground truth filenames (`Find: <find-filename>, GT:
    <gt-filename>`) in a small black font at the bottom left of the right-hand
    map canvas. When enabled, the text is automatically included in canvas
    screenshot exports.
-   **`AP Direction` Button**: Toggle button at the bottom of the legend that
    shows or hides the green AP Direction panel below the legend.
-   **`Toggle []` Button**: Button adjacent to `AP Direction` that toggles all
    legend layer checkboxes on or off simultaneously.

#### AP Direction Panel (Green Box)

Positioned directly below the legend, this panel provides real-time bearing and
accuracy readouts:

-   **White Compass Arrow**: Visualizes the estimated bearing from the
    pedestrian to the AP.
-   **Navy Blue Skinny Arrow**: Visualizes the true bearing according to ground
    truth.
-   **Numerical Metrics**:
    -   *Est. angle (degs)*: Estimated bearing angle.
    -   *True angle (degs)*: True survey bearing angle.
    -   *RMS / Mean angle error (degs)*: Angular tracking errors.
    -   *Est. dist. (m)*: Estimated distance to target.
    -   *True dist (m)*: Actual distance to target.
    -   *RMS / Mean dist error (m)*: Distance errors.
    -   *Error Ref*: Indicates ground truth source (`GT in log` or `GT File`).
-   **Mode Radios (`Enhanced` vs. `Phone`)**: Toggles whether bearing arrows
    and statistics reflect the Enhanced PDR solver or the raw Phone PDR solver.

## 5. Step-by-Step Practical Examples

### Example 1: Evaluating Wi-Fi 6E/7 Ranging Accuracy (Range Analysis Tab)

**Objective**: Determine ranging accuracy, linear bias, and channel stability of
a 6 GHz Wi-Fi Access Point across distances ranging from 1 to 20 meters.

1.  **Launch the Tool**:
    Start the local HTTP server (`python3 -m http.server 8000`) and open
    `http://localhost:8000/rtt-ranging-tool.html`. The tool opens directly to
    the **Range Analysis** tab.
2.  **Load the Dataset**:
    In the **File** subpanel, click the file input (or check `drag` to drop a
    file) and select a `WifiRttScan` RANGE log (e.g.,
    `wifi_rtt_range_6ghz.csv`).
3.  **Inspect Channel and Bandwidth**:
    In the **Parameters & Filters** subpanel under *Estimated vs Actual
    Distance*, confirm that `Bandwidth` is populated and `auto` is checked.
    Expand the **Data** subpanel and check `show` next to **Parsed Data** to
    verify the automatically detected channel, frequency, and band (e.g.,
    `Ch 77 (6335 MHz) (6GHz Wi-Fi 6E/7)`). The detected channel and bandwidth
    also appear in the title header of each chart card.
4.  **Configure Chart View**:
    In the **Chart** subpanel, select `2` columns and `Best Fit` aspect ratio.
    Ensure *Estimated vs. Actual Distance*, *CDF of Range Errors*, *Spread vs.
    Actual Distance*, and *Cramer-Rao Lower Bound* are checked.
5.  **Examine Linear Bias**:
    Inspect the *Estimated vs. Actual Distance* plot. Note the regression
    equation:
    $$y = 1.02x + 0.85$$
    An intercept of $+0.85$ m indicates an uncompensated internal antenna delay.
6.  **Apply Bias Removal**:
    In the **Parameters & Filters** subpanel, check **`Remove Bias`**.
    Notice that the trendline shifts to pass directly through the origin
    ($0, 0$), and the median error on the *CDF of Range Errors* chart drops
    significantly.
7.  **Inspect Multipath Spread**: On the *Estimated vs. Actual Distance* chart,
    click a measurement data point at a specific benchmark (e.g., $15\text{
    m}$). The **"Estimated Range Distribution Spread"** modal opens, displaying
    the spread and revealing any secondary multipath reflections.
8.  **Export Results**:
    Click **`Save PNG`** on the CDF chart card to save a publication-quality
    vector graphic, and click **`Save CSV`** to export the sorted percentile
    table.

### Example 2: Localizing an Indoor Access Point (AP Location Tab)

**Objective**: Reconstruct a pedestrian walking path in an office hallway,
filter multipath reflections, and localize an unknown Wi-Fi AP using
Gauss-Newton multilateration.

1.  **Switch to AP Location**:
    Click the **AP Location** tab button in the top navigation header.
2.  **Load Trajectory and Survey Data**:
    -   In the **File** subpanel, load your walking log (`FIND Log CSV`).
    -   Load the corresponding ground truth benchmark file (`gt_coords.csv`)
        into the **Ground Truth CSV** input.
    -   Observe the canvas: the red line shows raw phone PDR, the green line
        shows surveyor ground truth, and grey circles represent RTT range
        measurements.
3.  **Adjust Playback Range**:
    In the **Playback** subpanel, slide `slider-min` to step `5` and
    `slider-max` to step `45` to focus on the active corridor segment where RTT
    ranging was continuous.
4.  **Apply Measurement Filters**:
    Expand the **Filters** subpanel:
    -   Set **`Success Count Filter`** to `6` (requires at least 6 successful
        frames per burst).
    -   Set **`RSSI Filter`** to `-75.0` dBm to eliminate weak reflections.
    -   Set **`Std Dev Filter`** to `2.5` meters.
5.  **Configure Spatial RANSAC**:
    In the **Spatial Optimization** subpanel, select **`Spatial RANSAC + Auto
    Step length`**.
    -   Notice that anomalous large grey circles turn muted or disappear,
        leaving consistent intersection bands.
    -   The calibrated step length automatically adjusts (e.g., from `0.67` m to
        `0.71` m).
6.  **Run Gauss-Newton Multilateration**:
    In the **Gauss-Newton Optimization** subpanel:
    -   Set **Weighting** to `1 / Std-Dev^2`.
    -   Set **Initialization** to `Center of Trajectory`.
    -   The purple dot (Enhanced Target) snaps to the estimated AP
        coordinates, and `RMS Pos (m)` reports the convergence residual.
7.  **Evaluate Accuracy in the AP Direction Panel**:
    Look at the green **AP Direction** panel below the legend:
    -   Compare the white estimated arrow against the navy blue true ground
        truth arrow.
    -   Check *Mean angle error* (e.g., $4.2^\circ$) and *RMS dist error* (e.g.,
        $0.82\text{ m}$).
8.  **Generate Comprehensive Error Metrics**:
    In the **Metrics** subpanel, click **`Generate CDFs`**. Inspect the 50th and
    90th percentile position error curves, then click **`Save PNG`** to export
    the report.

### Troubleshooting Tips

-   **Charts appear blank or right panel is white**: Click the purple `reset`
    button or reload the log file. Ensure the CSV contains standard WiFiRttScan
    headers (`Range(m)`, `ActualRange(m)`, `BSSID`, etc.).
-   **Canvas map is blank or off-screen**: Click the **`Reset`** button in the
    zoom control overlay (top left of canvas) to auto-fit the view coordinates.
-   **Widgets wrap on the Playback title line**: Ensure your browser window is
    wide enough, or adjust the left sidebar width using the draggable vertical
    divider.
-   **Browser throttling during background animation**: Keep the browser tab
    active when running automated `Record` sequences to avoid background timer
    throttling.
