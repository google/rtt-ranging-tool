# RTT Positioning Tool

**RTT Positioning Tool** (`rttpos`) is an interactive, browser-based analysis,
visualization, and parameter optimization tool for indoor positioning using
Wi-Fi RTT (Round-Trip Time, also known as Wi-Fi FTM / Fine Timing Measurement,
IEEE 802.11mc & 802.11az) and Pedestrian Dead Reckoning (PDR).

To try out the RTT Positioning Tool click the link: [https://google.github.io/rtt-positioning-tool/rtt-positioning-tool.html](https://google.github.io/rtt-positioning-tool/rtt-positioning-tool.html) and view the operator instructions at [USER_GUIDE.md](USER_GUIDE.md)

> **Note:** This is not an officially supported Google product.

## Overview

The RTT Positioning Tool enables researchers and developers to evaluate, debug,
and tune indoor localization pipelines directly in the browser. It processes
recorded Wi-Fi RTT ranging measurements alongside floorplan imagery and walkable
path graphs to visualize trajectories, inspect per-point ranging behavior, and
optimize filter parameters against ground truth.

The primary input to the tool is the log file generated by the
**WifiRttLocator** Android indoor positioning app, available at no cost on the
Google Play Store. Additional inputs needed are the indoor floorplan overlay
(`.png`) that appears overlaid on the map view, and optionally an `.osm` file
defining the walkable routes inside a building.

### Key Features

-   **Data & Map Loading (`js/file-loader.js`)**: Load recorded Wi-Fi RTT
    measurement CSV logs, floorplan images, and OpenStreetMap (`.osm`) walkable
    path graphs via file picker or drag-and-drop mode.
-   **Measurement Pre-Filtering (`js/pre-filter.js`)**: Filter and preprocess
    raw RTT distance and RSSI measurements prior to position estimation.
-   **Access Point (AP) Selection (`js/apselector.js`)**: Configure and evaluate
    AP selection heuristics for multilateration.
-   **Location Engine & PDR Fusion (`js/location-engine.js`, `js/pdr.js`)**:
    Compute position estimates combining Wi-Fi RTT multilateration with
    Pedestrian Dead Reckoning (PDR) step/heading updates.
-   **Post-Filtering & Map Snapping (`js/post-filter.js`,
    `js/snap-filter.js`)**: Smooth estimated trajectories and snap positions
    onto walkable path networks.
-   **Parameter Optimizer (`js/param-optimizer.js`)**: Automatically sweep and
    optimize positioning and filtering parameters to minimize localization
    error.
-   **Interactive Visualization & Statistics (`js/charts.js`, `js/animation.js`,
    `js/statistics.js`)**: Inspect trajectories on an interactive Leaflet
    floorplan map, replay movement over time, view real-time Chart.js error/CDF
    plots, and compute summary error statistics.

## Getting Started

### Option 1: Run from Source

Because the modular version loads JavaScript files dynamically from the `js/`
directory, serve the directory using any local HTTP server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/rtt-positioning-tool.html` in your web browser.

### Option 2: Build a Standalone Single-File HTML Bundle

To bundle all HTML, CSS, and JavaScript modules into a single self-contained
HTML file (`rtt-positioning-out.html`) that can be opened directly from disk or
hosted on GitHub Pages:

```bash
./export.sh --inline
```

Open the generated `rtt-positioning-out.html` directly in any modern web
browser.

## Usage

1.  **Load Input Files**:
    -   **1. CSV Data**: Load the log file generated by the **WifiRttLocator**
        Android indoor positioning app (available at no cost on the Google Play
        Store), containing Wi-Fi RTT ranging measurements and optional ground
        truth coordinates.
    -   **2. Floorplan Image (`.png`)**: Load the indoor floorplan overlay
        (`.png`) that appears overlaid on the map view.
    -   **3. Walkable Paths (`.osm`)** *(Optional)*: Load an `.osm` file
        defining the walkable routes inside the building for map-snapping.
2.  **Configure Pipeline Stages**:
    -   Adjust parameters across the Pre-Filter, AP Selector, Location Engine,
        PDR, Post-Filter, and Snap Filter panels on the left sidebar.
3.  **Analyze & Optimize**:
    -   Inspect the resulting trajectory, ground truth comparison, error CDF
        charts, and playback animation.
    -   Use the Parameter Optimizer panel to automatically search for optimal
        filter settings.
