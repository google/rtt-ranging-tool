# RTT Ranging Tool

**RTT Ranging Tool** (`rttrange`) is an interactive, browser-based analysis,
visualization, and parameter optimization tool for Wi-Fi RTT (Round-Trip Time,
also known as Wi-Fi FTM / Fine Timing Measurement, IEEE 802.11mc & 802.11az)
ranging, distance estimation, and indoor Access Point (AP) localization.

To try out the RTT Map Tool click the link:
<https://google.github.io/rtt-ranging-tool/rtt-ranging-tool.html>
and view the operator instructions at [USER_GUIDE.md](USER_GUIDE.md).

> **Note:** This is not an officially supported Google product.

## Overview

The RTT Ranging Tool enables researchers and developers to evaluate, analyze,
and tune Wi-Fi RTT ranging measurements and indoor localization algorithms
directly in the browser. It provides two comprehensive analysis modes:

1.  **Range Analysis** (default tab): Provides in-depth statistical
    analysis and plotting of log data generated by **WiFiRttScan**, an
    application written by Google and freely available on Google Play. It
    generates error CDFs, spread distributions, RSSI correlation curves,
    time-series interval metrics, and Cramer-Rao Lower Bound (CRLB)
    theoretical modeling across 2.4 GHz, 5 GHz, and 6 GHz (Wi-Fi 6E/7)
    channels.
2.  **AP Location**: Reconstructs pedestrian trajectories from PDR step logs,
    visualizes ranging circles, and estimates AP coordinates and range bias
    using non-linear Gauss-Newton optimization. Multipath outliers can be
    filtered using spatial RANSAC, and localization accuracy can be evaluated
    against interpolated ground truth routes.

The tool processes CSV log files recorded by the **WiFiRttScan** app alongside
optional ground truth coordinate files (`gt_coords.csv`).

### Key Features

-   **Log Parsing & Ground Truth Interpolation (`js/parseData.js`)**: Loads and
    parses FIND1 Wi-Fi RTT CSV logs and ground truth coordinates, interpolating
    ground truth positions between anchor timestamps assuming constant walking
    speed.
-   **Gauss-Newton AP Location Solver (`js/ngLocationSolver.js`)**: Solves
    non-linear least squares for AP coordinates $(x, y)$ and ranging bias
    ($T_b$), supporting configurable initializations and weights (RSSI, range,
    measurement success count, and standard deviation).
-   **Interactive Trajectory & Map Plotting (`js/plot.js`)**: Renders PDR
    walking paths, ground truth routes, AP estimates, range circles, error
    circles, and path diversity indicators on an interactive HTML5 canvas with
    zoom, pan, and playback step filtering.
-   **Parameter Grid Optimizer (`js/paramOptimizer.js`)**: Automatically sweeps
    step length, diversity threshold, RSSI threshold, success count, std dev,
    and RANSAC spatial optimizations to find optimal positioning accuracy
    against ground truth.
-   **Error Metrics & CDF Analysis (`js/metrics.js`)**: Generates cumulative
    distribution function (CDF) charts and step error traces for angular and
    distance errors, with CSV and PNG export capabilities.
-   **WRS Range Analysis & Charting (`js/rangeAnalysis.js`)**: Generates eight
    customizable analytical charts:
    1.  *Estimated vs. Actual Distance* (with linear fit trendline, perfect
        distance reference line, and bias removal)
    2.  *CDF of Range Errors* (unsigned percentiles at 50%, 68%, 90%, 95%,
        99%, and maximum error)
    3.  *Spread vs. Actual Distance* (comparing estimate spread against standard
        deviation)
    4.  *Distribution of Range Error* (signed or unsigned histogram binning
        with mean, RMS, percentiles up to 99%, and maximum error)
    5.  *Distance vs. Std.Dev & RSSI* (dual Y-axis visualization)
    6.  *Std.Dev vs. RSSI* (scatter analysis of measurement noise against signal
        strength)
    7.  *Estimated Distance vs. Time* (time-series with interval statistics:
        mean, mean frequency in Hz, min, and max)
    8.  *Cramer-Rao Lower Bound (CRLB)* (theoretical bounds against SNR or RSSI
        for 20, 40, 80, 160, and 320 MHz bandwidths)
-   **Frequency-to-Channel & Auto Bandwidth (`js/rangeAnalysis.js`)**:
    Automatically calculates Wi-Fi channels and channel bonding bandwidths
    across 2.4 GHz (Channels 1–14), 5 GHz (Channels 32–177), and 6 GHz
    Wi-Fi 6E/7 (Channels 1–233, including 160 MHz bonding blocks).
-   **Unified Controller & IndexedDB Caching (`js/rtt-ranging-tool.js`)**:
    Manages dual sliders, animation playback, parameter persistence across page
    reloads, and export tools.

## Getting Started

### Option 1: Run from Source

Because the modular version loads JavaScript files dynamically from the `js/`
directory, serve the directory using any local HTTP server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/rtt-ranging-tool.html` in your web browser.

### Option 2: Build a Standalone Single-File HTML Bundle

To bundle all HTML, CSS, and JavaScript modules into a single self-contained
HTML file (`rtt-ranging-tool-out.html`) that can be opened directly from disk or
hosted on GitHub Pages:

```bash
./export.sh --inline
```

Open the generated `rtt-ranging-tool-out.html` directly in any modern web
browser.

## Usage

For comprehensive documentation of all subpanels, parameters, algorithms, and
practical examples, see the detailed [USER_GUIDE.md](USER_GUIDE.md).

1.  **Range Analysis Tab** (default tab):
    -   **Load Log**: Load a range log file (RANGE format) recorded by
        **WiFiRttScan** via the file picker or drag-and-drop.
    -   **Configure Filters**: Set distance boundaries, time window, bias
        normalization, and grid formatting.
    -   **Inspect Charts**: View interactive charts, inspect per-distance spread
        modals by clicking data points, and export individual chart data to CSV
        or PNG.
2.  **AP Location Tab**:
    -   **Load Logs**: Load a Wi-Fi RTT CSV log (FIND format) and optional
        ground truth coordinates (`gt_coords.csv`).
    -   **Configure Parameters**: Adjust playback steps, filter parameters,
        Gauss-Newton weighting, and spatial RANSAC settings.
    -   **Analyze & Optimize**: Inspect trajectory errors on the interactive
        plot, evaluate CDF curves via the Metrics button, or run the Parameter
        Optimizer to determine optimal filter configurations.
